Digital Investigation · Concept Draft
The idea

Find anyone. Legally. Without leaving your desk.

IdentityEngine is a fully digital private investigator — a service that uses OPSEC methods to legally find information on a suspect, without any physical presence required. It starts with the basics: people-search-style tools, social media scanning, metadata extraction. Then it goes deeper: AI builds a full profile, finds related nodes, discovers alt-accounts, and correlates accounts by writing style.

The approach

OPSEC methods. Legal. AI-assisted. Automated.

The basic premise: an online investigation company that runs OPSEC to find information. Use people-search tools. Find all images on social media and auto-scan them for metadata with AI. Have AI build a full profile on the individual of interest. Investigate nodes it suspects are related to the suspect. Build a full report. Find alt-accounts using writing-style analysis — the same method as the referenced video, where AI sees someone's writing style and filters correlated accounts with the same style.

Capability 01

People-Search Tools

Start with the basics: people-search-style tools that aggregate publicly available information on a subject. Name, address history, phone numbers, known associates — the standard open-source intelligence stack.

OSINT
Capability 02

Social Media Image Scanning

Find all images on a subject's social media and auto-scan them for metadata with AI. EXIF data, geolocation hints, device fingerprints, timestamps — everything the images reveal that isn't visible on the surface.

AI + Metadata
Capability 03

Full Profile Building

AI takes all the gathered data and builds a full profile on the individual of interest. Connections, habits, locations, accounts, timeline — a structured report that puts the whole picture together.

AI Profile
Capability 04

Node Investigation

Investigate nodes the AI suspects are related to the suspect. Follow the connections. Map the network. Each related node gets checked, and the results feed back into the profile.

Network Mapping
Capability 05

Alt-Account Discovery

Find alt-accounts using writing-style analysis. AI sees someone's writing style and filters for correlated accounts with the same style — the same method referenced in the source video. One person, many accounts, all identified.

Stylometry
Capability 06

Full Report Generation

Everything comes together in a full report on the individual of interest. Structured, sourced, and ready to use. The final output of the investigation — a document that says what was found, how, and where it came from.
